Как получить токен Discord
  1. Открой Discord в браузере и войди в аккаунт.
  2. Нажми F12 → вкладка Console.
  3. Вставь: (webpackChunkdiscord_app.push([[''],{},e=>{m=[];for(let c in e.c)m.push(e.c[c])}]),m).find(m=>m?.exports?.default?.getToken!==void 0).exports.default.getToken()
  4. Скопируй строку без кавычек и вставь её сюда.

Токен = полный доступ к аккаунту. Никому его не передавай. Вход по токену нарушает правила Discord — аккаунт могут заблокировать.

Не подключено

По умолчанию вход использует учётные данные официального клиента Telegram: достаточно номера и кода. Выключи, чтобы вписать свои api_id/api_hash.

Код из Telegram
Код придёт в Telegram или по SMS.
Открой Telegram на телефоне → Настройки → Устройства → Подключить устройство и наведи камеру на этот код.
Свои api_id и api_hash (если выключены встроенные)
  1. Зайди на my.telegram.org и войди по номеру телефона.
  2. Открой API development tools.
  3. Заполни название (любое) и платформу, нажми Create application.
  4. Скопируй App api_id и App api_hash сюда.

Проще всего — «Войти по QR-коду»: отсканируй код в приложении Telegram, и вход произойдёт без всяких кодов.

При входе по коду Telegram со встроенными данными отправляет код в приложение Telegram (на телефон или другое устройство), а не по SMS. Если код не приходит — используй вход по QR-коду. При двухфакторной защите дополнительно спросим пароль.

Если Telegram в твоей сети заблокирован, укажи SOCKS5-прокси или включи VPN — без этого соединение не установится.
