# ЛС — мини-окно с личными сообщениями Discord и Telegram

Маленькое окно, которое всегда висит поверх других окон и показывает личные
сообщения из **Discord** и **Telegram**. Сверху три кнопки-вкладки — можно
переключаться между мессенджерами и музыкой, у каждого мессенджера свой статус
и счётчик непрочитанных.

- Список чатов: каждый собеседник — отдельный диалог, сообщения не смешиваются.
  В списке видно последнее сообщение, время и число непрочитанных.
- **Новое сообщение** в Discord и Telegram: можно написать человеку, с которым
  ещё не переписывался — найди его по имени/`@нику` или вставь ID (Discord),
  `@ник`, телефон или ID (Telegram).
- Окно без рамки, перетаскивается за заголовок, сворачивается в трей.
- Показывает автора, аватар, время и текст. **Медиа видно прямо в окне**:
  фото, кружки, видео, GIF и стикеры и в Discord, и в Telegram.
- **Просмотр медиа внутри приложения**: клик по фото/кружку открывает его
  на весь экран — ничего не скачивается и не открывается в браузере.
- **Эмодзи и стикеры**: кнопка **😊** в поле ввода открывает панель с эмодзи
  (с поиском по названию) и стикерами обоих мессенджеров. Панель не перекрывает
  сообщения — лента сдвигается вверх и прокручивается вниз, как в Telegram.
  **Стикеры разбиты по наборам (пакам), как в Telegram**: сверху — полоска
  наборов с обложками, ниже — стикеры выбранного набора. Показаны **все** наборы,
  добавленные в аккаунт Telegram, а не первые двенадцать.
- **Гифки (GIF)**: в той же панели есть вкладка **GIF** — поиск через открытый
  сервис **Openverse** (ключ не нужен, ничего вводить не надо), отправка
  **по ссылке** и **файлом с диска**.
- **Пересылка сообщений** (ПКМ по сообщению → «Переслать»), в том числе
  **между мессенджерами**: из Telegram в Discord и наоборот, с сохранением
  вложения. Пересылка **Telegram → Telegram** идёт настоящей пересылкой — как в
  самом Telegram, с пометкой **«Переслано»**. У пересланного сообщения видно
  **имя автора**: «↪ Переслано от …».
- **Подпись под медиа**: если фото/видео отправлено с текстом, картинка
  показывается сверху, а текст — под ней, как одно сообщение.
- **Статусы Telegram**: у аватарки собеседника и в шапке чата видно **в сети**,
  **не активен (недавно)** или **офлайн** — с временем и датой последнего визита.
  Обновляется «на лету».
- **Скриншот из буфера обмена**: сделай снимок (**Win+Shift+S**) и вставь его
  в поле ввода (**Ctrl+V**) — картинка уйдёт вложением. Текст из поля станет
  подписью.
- **Редактирование своих сообщений** — ПКМ по своему сообщению → «Изменить».
- **Удаление своих сообщений** — ПКМ по своему сообщению. В Telegram можно
  **«Удалить у себя»** или **«Удалить у всех»**, в Discord — «Удалить
  сообщение». Есть и **«Убрать из оверлея»** — сообщение исчезнет только в окне,
  а в Discord/Telegram останется.
- **Прикрепить файл** — кнопка **📎** в поле ввода: фото, документы, **mp3**,
  **mp4** и другие файлы, как в обычных мессенджерах (до 50 МБ; Discord — до
  8 МБ). Текст из поля ввода уходит подписью к файлу.
- **Удаление и игнорирование чатов** — ПКМ по чату → «Удалить чат» (только в
  оверлее) или **«Удалить чат и игнорировать»**: чат пропадёт из окна и больше
  не будет появляться. Вернуть его можно в настройках.
- Звук и системное уведомление Windows, когда окно скрыто или открыта другая вкладка.
- Можно фильтровать: показывать сообщения только от выбранных людей.
- Цитата ответа: видно, на какое сообщение ответили — клик по цитате переходит
  к оригиналу и подсвечивает его (подсветка держится до первого клика или
  нажатия клавиши).
- Прозрачность и размер текста настраиваются.
- **Музыка из YouTube** — отдельная вкладка: обычные клипы, длинные миксы на
  2–4 часа и плейлисты. Играет **только звук и без рекламы**, а если YouTube
  что-то поменяет — автоматически включается встроенный плеер YouTube.
  Есть блок **рекомендаций** — популярные песни и плейлисты, а рядом с любым
  треком подбирается «радио» из похожих песен.
- История последних 300 сообщений на каждый мессенджер сохраняется между запусками.

> ⚠️ **Discord.** Приложение входит в аккаунт по токену (selfbot). Это
> **нарушает правила Discord**, и аккаунт могут заблокировать. Токен даёт полный
> доступ к аккаунту — никому его не показывай.
>
> ⚠️ **Telegram.** Вход обычным аккаунтом (MTProto) разрешён правилами Telegram.
> Но по умолчанию приложение использует **встроенные** `api_id`/`api_hash`
> официального клиента — это удобно (не нужен my.telegram.org), однако
> **нарушает правила Telegram** и теоретически грозит блокировкой. Можно вписать
> свои данные и отключить встроенные.

## Запуск

Установка не нужна — приложение уже собрано в один `.exe`.

**Самый простой способ:** двойной клик по ярлыку **«ЛС — Discord и Telegram»**
на рабочем столе (он уже создан).

Либо запусти файл напрямую:

```
dist\DM Overlay-win32-x64\DM Overlay.exe
```

Весь этот каталог можно скопировать куда угодно (например, на флешку) — приложение
запустится оттуда. Настройки и история при этом хранятся отдельно, в
`%APPDATA%\discord-dm-overlay`, и сохраняются между запусками.

> Не удаляй и не переименовывай папку `dist\DM Overlay-win32-x64` после запуска —
> в ней рядом с `.exe` лежат служебные файлы Electron.

### Если запускаешь из исходников

1. Двойной клик по **`Запустить.bat`**.
   При первом запуске он сам установит зависимости (нужен интернет).
2. В открывшемся окне нажми **⚙** (настройки).
3. Выбери вкладку **Discord** или **Telegram** и подключи аккаунт (см. ниже).
4. Готово: точка в заголовке станет зелёной, новые личные сообщения начнут
   появляться в окне.

Если что-то не запускается — используй **`Запустить-отладка.bat`**, он покажет
console с ошибками.

### Пересобрать .exe

```bash
npm install
npm run build
```

Готовое приложение появится в `dist\DM Overlay-win32-x64\DM Overlay.exe`.

### Установщик (чтобы поделиться с другим человеком)

Для распространения есть обычный установщик Windows:

```bash
npm run installer
```

Результат — один файл **`release\DM-Overlay-Setup-<версия>.exe`** (~106 МБ).
Его можно просто скинуть человеку: он запускает файл, выбирает папку и
пользуется приложением. Отдельно ничего ставить не нужно.

- **Установка** — обычный мастер: выбор папки, ярлыки на рабочем столе и в
  меню «Пуск», запись в «Программы и компоненты» (её видно в списке
  установленных приложений и можно удалить оттуда).
- **Обновление** — если запустить новый установщик поверх старого, настройки,
  входы в аккаунты и история сохраняются.
- **Удаление** — открой тот же установщик, и он спросит: «Удалить приложение и
  все его данные?». Ответ «Да» удаляет и программу, и папку с данными
  `%APPDATA%\discord-dm-overlay` — на компьютере не остаётся ничего.

Настройки и история у portable-версии и у версии из установщика общие —
одна и та же папка `%APPDATA%\discord-dm-overlay`.

### Discord: как получить токен

1. Открой Discord в браузере (не в приложении) и войди в аккаунт.
2. Нажми `F12` → вкладка **Console**.
3. Вставь и нажми Enter:

```js
(webpackChunkdiscord_app.push([[''],{},e=>{m=[];for(let c in e.c)m.push(e.c[c])}]),m).find(m=>m?.exports?.default?.getToken!==void 0).exports.default.getToken()
```

4. Скопируй полученную строку **без кавычек** — это и есть токен.
5. Вставь его в настройках Discord и нажми **«Сохранить и подключить»**.

> Если Discord ругается на вставку кода, набери в консоли
> `allow pasting` и попробуй снова.

### Написать новому человеку

Если с собеседником ещё нет переписки, его нет в списке чатов. Чтобы начать диалог,
открой список чатов нужного мессенджера и нажми кнопку **«＋ Новое»** (внизу справа).

**Discord:**

1. Найди человека по имени или `@нику` — приложение поищет среди друзей Discord
   и тех, с кем уже есть переписка, и покажет совпадения. Выбери нужного.
2. Либо вставь **ID пользователя** (Discord → Настройки → Дополнительно →
   Режим разработчика, затем ПКМ по человеку → «Копировать ID») и нажми
   **«Открыть»** — так можно написать любому, даже не из друзей.
3. Откроется чат — напиши сообщение и отправь. Чтобы это работало, в настройках
   Discord должна быть включена опция **«Разрешить ответы»**.

**Telegram:**

1. Введи **`@ник`**, **номер телефона** или **ID** и нажми **«Открыть»** —
   приложение откроет с ним чат, даже если переписки раньше не было.
2. Или найди человека по имени — приложение поищет среди твоих контактов
   Telegram и покажет совпадения.
3. Напиши сообщение и отправь (нужна включённая опция **«Разрешить ответы»**).

### Пересылка и редактирование

- **Переслать**: правый клик по сообщению (или кнопка **⋯** при наведении) →
  **«➡️ Переслать»**, затем выбери получателя. Чаты Discord и Telegram **не
  смешиваются** — в окне пересылки есть **две вкладки** («Discord» и «Telegram»
  с числом чатов), переключайся между ними. Так можно переслать сообщение
  **из одного мессенджера в другой**, вложение тоже переедет.
- **Пересылка внутри Telegram**: если и источник, и получатель — Telegram,
  сообщение уходит **настоящей пересылкой**, как в самом Telegram, и получатель
  видит пометку **«Переслано»**. Если пересылаешь самому себе, пометки не будет —
  Telegram считает это копией своего сообщения.
- **Изменить своё сообщение**: правый клик по своему сообщению → **«✏️ Изменить»**,
  поправь текст и отправь. Отредактированное сообщение помечается словом
  «изменено».
- **Скопировать текст**: правый клик → **«📋 Копировать текст»**.
- **Ответить**: правый клик по чужому сообщению → **«↩ Ответить»**.

### Статусы собеседников (Telegram)

У аватарки собеседника в списке чатов и в шапке открытого диалога видно его
статус:

- 🟢 **в сети** — сейчас онлайн;
- 🟡 **не активен (недавно)** — заходил(а) недавно (в течение недели/месяца
  подпись уточняется);
- ⚪ **офлайн** — в шапке показано, **когда** человек был(а) в сети последний
  раз: «был(а) в сети сегодня в 21:40», «вчера в 09:15» или «12.11.2026 в 18:03».

Статусы обновляются «на лету». Показываются только для Telegram: Discord не
отдаёт онлайн-статус собеседника в личных сообщениях.

### Удаление сообщений

Правый клик по **своему** сообщению → выбери действие:

- **Telegram:** «🗑 Удалить у себя» — сообщение исчезнет только у тебя;
  «🗑 Удалить у всех» — удалится у собеседника тоже.
- **Discord:** «🗑 Удалить сообщение» — удаляется у всех (у Discord нет удаления
  «только у себя»).
- **«🙈 Убрать из оверлея»** — сообщение пропадёт только в этом окне, а в
  Discord/Telegram **останется как было**.

### Удаление и игнорирование чатов

Правый клик по **чату** в списке (или по шапке открытого чата):

- **«🗑 Удалить чат»** — чат исчезает только в оверлее. В Discord/Telegram
  переписка **не удаляется**, но и в окне больше не появится, пока не придёт
  новое сообщение.
- **«🚫 Удалить чат и игнорировать»** — чат исчезает и больше **не появляется**
  в окне даже при новых сообщениях. Это тоже касается только оверлея.
- Вернуть игнорируемый чат: **⚙ Настройки** → вкладка нужного мессенджера →
  **«Игнорируемые чаты»** → **«Вернуть»**.

### Прикрепление файлов

Кнопка **📎** в поле ввода отправляет **фото, документ, mp3, mp4** и другие
файлы — Telegram сам определяет тип (картинка, аудио, видео, документ).
Текст, набранный в поле ввода, станет **подписью** к файлу. Ограничения: до
**50 МБ** (Discord — до **8 МБ**).

**Скриншот из буфера.** Сделай снимок экрана (**Win+Shift+S**), затем щёлкни по
полю ввода и нажми **Ctrl+V** — картинка уйдёт вложением. Текст в поле станет
подписью. Работает и с любым другим изображением в буфере обмена.

### Стикеры

Панель **😊** в поле ввода, вкладка **Стикер**. Стикеры показаны **по наборам**,
как в самом Telegram:

- Сверху — **полоска наборов** с обложками. Прокручивается по горизонтали
  (в том числе колёсиком мыши), остаётся на месте при прокрутке стикеров.
- Ниже — сетка стикеров **выбранного набора**. Анимированные стикеры
  проигрываются прямо в панели.
- **Поиск** ищет сразу по всем наборам (по названию набора и эмодзи) и
  показывает результаты одной плоской сеткой.

Для Telegram загружаются **все наборы, добавленные в аккаунт** (без ограничения
в 12 наборов и 200 стикеров). Discord отдаёт доступные стикеры серверов одним
набором **«Discord»**.

### Гифки (GIF)

Панель **😊** в поле ввода, вкладка **GIF** — три способа отправить гифку:

1. **Поиск.** Введи запрос и нажми **Enter** — приложение ищет гифки через
   открытый сервис **Openverse** ([openverse.org](https://openverse.org)).
   Результаты показываются сеткой, под ними подпись **«Поиск гифок: Openverse»**.
   Клик по гифке — отправка.
2. **По ссылке.** Вставь ссылку на гифку (`.gif`, `.mp4`, Giphy/Klipy и т.п.) и
   нажми **→** — приложение скачает её и отправит.
3. **Файлом.** Нажми **«📁 С ПК»** и укажи гифку на диске.

> **Ключ не нужен.** Поиск гифок работает через **Openverse** — открытый каталог
> без регистрации и без ключа, ничего вводить не нужно. Поиск лучше работает на
> английском; частые русские слова (привет, спасибо, кот, любовь и т.п.)
> приложение переводит автоматически. При пустом запросе показываются популярные
> гифки.

> **Про правила.** Приложение не обходит лицензии и ограничения: гифки
> отправляются обычным способом, доступным любому аккаунту, — без обхода
> Discord Nitro или платных функций Telegram.

### Telegram: вход

Telegram не отдаёт личные сообщения ботам, поэтому приложение подключается как
обычный пользовательский клиент (MTProto). По умолчанию используются **встроенные
данные официального клиента Telegram** — регистрировать приложение на
my.telegram.org не нужно.

1. Открой настройки вкладки **Telegram**.
2. Введи номер телефона (и SOCKS5-прокси, если Telegram заблокирован).
3. Нажми **«Войти по QR-коду»** — покажется QR-код. Открой Telegram на телефоне →
   **Настройки → Устройства → Подключить устройство** и наведи камеру. Вход
   произойдёт без кода.
4. Либо нажми **«Войти по коду»**: Telegram пришлёт код подтверждения — введи его
   в появившемся поле. Если включена двухфакторная защита, дополнительно спросим
   пароль.

> **Почему код может не приходить.** Со встроенными данными Telegram шлёт код
> подтверждения **только в приложение Telegram** (на телефон или другое устройство
> с твоим аккаунтом), а не по SMS, и иногда не доставляет его вовсе. Поэтому
> надёжнее **вход по QR-коду** — он работает без кода вообще.

Сессия сохраняется, поэтому при следующем запуске вход происходит автоматически.

**Свои api_id / api_hash (необязательно).** Выключи переключатель
**«Встроенные данные Telegram»** — поля `api_id`/`api_hash` станут доступны.
Получить их можно на **my.telegram.org**:

1. Зайди на **my.telegram.org** и войди по номеру телефона.
2. Открой **API development tools**, заполни название (любое) и платформу,
   нажми **Create application**.
3. Скопируй **App api_id** и **App api_hash** в настройки и нажми **«Войти»**.

> ⚠️ Встроенные данные — это `api_id` чужого (официального) клиента. Telegram
> может расценить это как нарушение правил и заблокировать аккаунт. Если боишься
> за аккаунт — выключи переключатель и используй свои `api_id`/`api_hash`.

> **Если Telegram в твоей сети заблокирован**, соединение не установится.
> Включи VPN или укажи SOCKS5-прокси в настройках Telegram
> (`host:port` или `user:pass@host:port`). Список серверов Telegram по умолчанию
> недоступен в некоторых сетях — приложение сообщит об этом понятной ошибкой.

## Музыка

Отдельная вкладка **«Музыка»** — можно слушать YouTube, не открывая браузер.

- **Рекомендации** (открывается по умолчанию): подборка популярных песен и
  плейлистов. Клик по песне играет её, звёздочка **★** сохраняет в «Мою музыку»,
  клик по плейлисту добавляет его песни в список и запускает.
- **Поиск**: введи название в строке сверху и нажми **Найти**. Результаты
  появятся на вкладке **«Результаты»**.
- **Ссылка**: вставь ссылку на видео, плейлист или длинный микс (2–4 часа) и
  нажми **Найти** — всё добавится в **«Мою музыку»** и сразу заиграет.
- **Сохранённый список** («Моя музыка») хранится между запусками. Звёздочка
  **★** сохраняет трек, повторное нажатие убирает его из списка.
- Играет **только звук, без рекламы**: приложение достаёт аудио-дорожку через
  `yt-dlp` и проигрывает её. Это работает и для длинных миксов «одним роликом».
- **Откат**: если аудио достать не удалось (или это прямой эфир), открывается
  встроенный плеер YouTube — там есть видео и возможна реклама, но музыка
  продолжит играть.

Внизу — панель управления: обложка, название, **◀ / ▶** (предыдущий и
следующий трек), **Играть/пауза**, полоса перемотки, время, громкость и режим
(«Без рекламы» или «Плеер YouTube»). Плейлист воспроизводится по порядку.

> `yt-dlp` обновляется кнопкой **«Обновить yt-dlp (музыка)»** в настройках →
> **Общие**. Делай это, если YouTube перестал отдавать звук.

## Настройки

Настройки разделены на две вкладки: **Discord** и **Telegram**. У каждого
мессенджера свои фильтры и разрешение на ответы.

- **Показывать только от** — ники, `@ники` или ID через запятую. Пусто = все
  личные сообщения. Пример для Discord: `best_friend, 123456789012345678`,
  для Telegram: `Мама, @friend, 123456789`.
- **Показывать мои сообщения** — твои ответы тоже видны в ленте.
- **Разрешить ответы** — включает поле ввода для этого мессенджера.
- **Игнорируемые чаты** — список чатов, которые скрыты в оверлее (добавляются
  через ПКМ по чату → «Удалить чат и игнорировать»). Кнопка **«Вернуть»** убирает
  чат из игнорируемых.
- **Уведомления Windows** — всплывашки, когда окно не в фокусе или открыта
  другая вкладка.
- **Звук** — короткий сигнал при новом сообщении.
- **Поверх всех окон** — окно не прячется за другими приложениями.
- **Прозрачность / размер текста** — внешний вид.
- **Обновить yt-dlp (музыка)** (вкладка «Общие») — обновляет загрузчик звука для
  вкладки «Музыка», если YouTube перестал отдавать аудио.

## Где хранятся данные

`C:\Users\<имя>\AppData\Roaming\discord-dm-overlay\`

- `config.json` — настройки, токен Discord и сессия Telegram (в открытом виде,
  локально), список «Моей музыки», громкость и списки игнорируемых чатов;
- `history.json` — последние сообщения по каждому мессенджеру;
- `bin\yt-dlp.exe` — копия загрузчика музыки (её и обновляет кнопка в настройках).

Кнопка «Папка с данными» в настройках открывает её.
Скачанные вложения Telegram лежат во временной папке `%TEMP%\dm-overlay`.

## Если не работает

| Проблема | Что делать |
| --- | --- |
| Discord: «Неверный токен» | Токен скопирован не полностью или устарел — получи новый. |
| Сообщения не приходят | Проверь фильтр «Показывать только от» и статус в заголовке. Нажми «Переподключиться». |
| Telegram: «Не отвечает» | Включи VPN или укажи SOCKS5-прокси, затем нажми «Переподключиться». |
| Telegram: не приходит код | Со встроенными данными код идёт только в приложение Telegram. Проверь телефон/другие устройства или войди по **QR-коду**. |
| Telegram: просит пароль | Это пароль двухфакторной защиты, который ты задал в Telegram. |
| Telegram: «Неверный api_id / api_hash» | Только для своих данных: перепроверь значения на my.telegram.org или включи встроенные данные Telegram. |
| Discord: никого не нашёл при «＋ Новое» | Поиск идёт только по друзьям — вставь ID пользователя вручную. |
| Медиа не показывается (только плашка файла) | Telegram-медиа качается при первом показе — подожди пару секунд; старые сообщения подгружаются из Telegram. Если чат очень старый, открой его заново. |
| Пересылка не проходит | Нужна включённая опция **«Разрешить ответы»** у получателя. Учти: некоторым ботам Discord личные сообщения закрыты. |
| «Не удалось переслать: … IMAGE_PROCESS_FAILED» | Картинка битая или слишком маленькая — приложение повторяет отправку документом. |
| Прикрепить: «Файл больше 50 МБ» | Для вложений лимит 50 МБ, для Discord — 8 МБ. |
| Удалил/игнорировал чат, а он вернулся | «Удалить чат» скрывает до нового сообщения; чтобы чат не появлялся совсем, используй «Удалить чат и игнорировать». Вернуть — в настройках, «Игнорируемые чаты». |
| GIF: поиск пустой | Каталог Openverse небольшой — попробуй другой запрос (лучше на английском). Отправка по ссылке и файлом работает всегда. |
| Окно не видно | Нажми `Ctrl + Shift + D` или кликни иконку в трее. |
| Музыка не играет, «Без рекламы» срывается на плеер | Так бывает при сбое извлечения — нажми «Обновить yt-dlp (музыка)» в настройках. |
| Музыка: ничего не нашлось | Проверь интернет; YouTube может быть недоступен в твоей сети. |
| Не приходят уведомления Windows | Включи их в настройках; проверь, что для системы не включён режим «Не беспокоить». |
| Ничего не запускается | Запусти `Запустить-отладка.bat` и посмотри текст ошибки. |

## Технические детали

- Electron + чистый Node.js.
- Discord: собственный минимальный клиент — Gateway v10 по WebSocket, REST v10.
  Только чтение личных сообщений (`MESSAGE_CREATE`, каналы типа DM/группа).
- Telegram: [GramJS](https://github.com/gram-js/gramjs) (MTProto, `telegram`),
  обработчик `NewMessage`, только приватные чаты. Поддерживается SOCKS5-прокси.
  Вход — по QR-коду (`signInUserWithQrCode`) или по коду из приложения.
- **Медиа.** Фото, кружки, видео, GIF и стикеры подгружаются лениво (по мере
  прокрутки). Байты Telegram приходят в интерфейс по IPC и показываются как
  `blob:`-объекты — в браузер ничего не уходит. Аватарки Telegram тоже тянутся
  по IPC и кэшируются. Клик по изображению открывает встроенный просмотрщик.
- **Стикеры.** Telegram отдаёт список наборов через `messages.GetAllStickers`, а
  затем документы каждого набора через `messages.GetStickerSet` (параллельно,
  небольшими порциями, чтобы не улететь в флуд-лимит) — один набор = один пак с
  обложкой. Отправка идёт через `messages.SendMedia`. Discord — стикеры серверов
  через `/guilds/{id}/stickers` (собираются в один пак «Discord») и отправка
  `sticker_ids`.
- **Гифки.** Поиск — открытый API **Openverse** (без ключа; фильтр по `filetype:
  gif`, подпись «Поиск гифок: Openverse», частые русские запросы переводятся на
  английский). Гифку можно отправить ссылкой или файлом. В Telegram настоящая
  гифка уходит с `DocumentAttributeAnimated` и без
  `forceDocument` — сервер сам конвертирует её в беззвучный MP4 (анимацию).
  Discord отправляет файл как обычное вложение; ничего платного не обходится.
- **Пересылка.** Приложение достаёт сообщение из истории, скачивает вложение
  (URL Discord или `downloadMedia` Telegram) и отправляет его в целевой чат
  (`sendFile` Telegram или multipart-загрузка Discord). Для **Telegram → Telegram**
  используется настоящая пересылка (`messages.ForwardMessages`) — сервер сам
  сохраняет пометку «Переслано».
- **Вложения.** Кнопка **📎** открывает системный выбор файла и отправляет его
  через `sendFile` (Telegram сам определяет тип по содержимому — фото, аудио,
  видео или документ). Подпись берётся из поля ввода, ответ — из цитаты.
- **Удаление сообщений.** Своё сообщение удаляется через `messages.DeleteMessages`
  (`revoke` = «у всех» / «у себя») в Telegram и `DELETE /channels/{id}/messages/{id}`
  в Discord. Режим «только в оверлее» в мессенджер не ходит вообще — правится лишь
  локальная история.
- **Игнорируемые чаты.** Список хранится в `config.json` (`discord.ignored` /
  `telegram.ignored`) как `[{ id, title }]`. Игнорируемый чат отсекается при
  приёме сообщений и при загрузке истории, поэтому не появляется даже после
  перезапуска. Удаление/игнорирование чата трогает **только** оверлей.
- Музыка: [yt-dlp](https://github.com/yt-dlp/yt-dlp) — аудио-дорожка YouTube
  извлекается напрямую и играет в обычном `<audio>`, без рекламы. Если не
  получилось — встроенный плеер `youtube-nocookie`. Рекомендации берутся из
  чарта YouTube Music, «радио» по треку и поиска плейлистов. Вывод yt-dlp
  читается в UTF-8 (`--encoding utf-8`), поэтому русские названия не портятся.
  Список и громкость хранятся в `config.json`.
- Контекстная изоляция включена, `nodeIntegration` выключен, CSP ограничивает
  загрузку ресурсов.
